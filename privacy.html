Privacy Policy

Last updated: 2026-09-09

Overview

Hermes Fleet is a personal, non-commercial automation project. This application uses Google APIs (Gmail, Calendar, Drive) solely for the account owner's own automation workflows: reading and sending mail related to service registrations, and managing documents and calendars belonging to the owner.

Data Access

The application requests OAuth scopes for Gmail (read, send, modify), Calendar, Drive, Contacts (read-only), Sheets and Documents. Access is limited to the account that explicitly grants consent. No other accounts' data is accessed.

Data Use & Storage

All data is processed and stored locally on the owner's own infrastructure. Data is never sold, rented, shared with third parties, used for advertising, or used to train machine-learning models. Mail content is read only to complete automation tasks requested by the owner (e.g. account verification codes for API services the owner registers to).

Google User Data

Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. See: https://developers.google.com/terms/api-services-user-data-policy

Data Retention & Deletion

Emails and files accessed by the application are not copied to external servers. The user can revoke access at any time via their Google Account permissions page, after which all stored OAuth tokens are invalidated.
